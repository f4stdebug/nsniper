Инструмент для поиска свободных юзов на [guns.lol](https://guns.lol) + парсинг фришных прокси.

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python gunslol.py
```

Всё через меню:

```
1) Искать ники
2) Спарсить прокси
3) Отсортировать прокси (proxies.txt)
4) Оценить найденные ники по красоте
0) Выход
```

## Моды (спросит при поиске)

| Мод | инфо |
|---|---|
| `beauty` | цифры 1-100 + короткие 1-3 (буквы+цифры) + слова — по приоритету |
| `numbers` | числа 1-100 |
| `short` | все комбинации 1-3 символа (буквы+цифры) |
| `two` | ровно 2 символа (буквы+цифры) |
| `words` | встроенный словарь английских слов |
| `repeaters` | `aa` / `aaa` / `aaaa` |
| `combos` | ровно 3 символа `a-z0-9` |
| `custom` | вручную: длина цифр / букв / букв+цифр |
| `file` | список юзов из файла |

Можно выбрать несколько через запятую, например `1,4`.

## Что ещё спросит

- сколько кандидатов проверять (лимит)
- сколько потоков
- файл для свободных (по умолчанию `available.txt`)
- скрывать ли занятые
- доп. символы (`._`)

Прокси подхватываются сами: если есть `proxies.txt` — проверит; если пусто — спарсит открытые источники, проверит и сложит живые в `proxies.txt`.

## Логи

Пишет `latest.log`. Свободные ники — в `available.txt`, рейтинг по красоте — в `available_ranked.txt`.
